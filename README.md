# Подбор автозапчастей и аналогов

Клиент на React + Redux Toolkit + Bootstrap для веб-сервиса «Проценка»
(`api.favorit-parts.ru/hs/hsprice/`, документация — `wsprice.pdf`).

1. Вводите артикул — после паузы в наборе запрашивается список производителей.
2. Выбираете производителя — запрашиваются деталь и её аналоги (`brand` + `analogues=on`),
   результат показывается таблицей предложений по складам: деталь, склад, дата отгрузки, остаток, цена.

Цена берётся из склада (`warehouses[].price`), как требует документация; позиции без складов
показываются с пометкой «нет в наличии».

## Запуск

```bash
npm install
npm run dev
```

В `.env` указан демо-ключ из документации.

## Структура

- `src/api/partsApi.js` — запросы к API, обработка ошибок и нормализация ответа
- `src/store/searchSlice.js` — состояние двух этапов (loading / succeeded / failed), отбрасывание устаревших ответов
- `src/components/` — поле поиска, список производителей, таблица предложений, лоадер и блок ошибки
